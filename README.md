# Grand-Canyon-ITS

This repository will have the code for different intelligent transportation systems (ITS) projects happening at Grand Canyon, starting spring break 2023. The project is looking at the following park-level issues:
- Long lines at the South Entrance station
- Parking at Visitor Center
- General emergency management and evacuation procedures
- Transit Information can be difficult to find, especially when routes change across seasons
- Speeding in local roads throughout Park
- Visitor navigation to the Rim/general wayfinding
- Desert View Drive/East Entrance Road Closures

### GTFS: Improved Travel Information

Currently, there are no transit route options if a visitor is using navigation apps. There is information on [NPS.gov](https://www.nps.gov/grca/planyourvisit/shuttle-buses.htm), but this hasn't been digitally transformed into a usable GTFS for the 4 shuttle routes. 

### Parking Lot Trends: Improved Travel Information, Closing Parking Lots in Real-Time

Grand Canyon currently uses a series of sandwich boards to inform visitors about parking lots that are full and about other parking lots.
